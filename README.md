# PMJ Career Navigator｜PM/PjM 職涯導航

第 2 組（G2）課程專題網站原型｜AI 世代產品經理職涯策略與專案管理導論
指導老師：Prof. Shihmin Lo

## 網站結構

整個網站只有一個檔案 `index.html`，HTML、CSS、JavaScript 都寫在裡面，不需要建置，直接用 GitHub Pages 從 `main` 分支根目錄發布。

| 區塊 | 內容 |
|---|---|
| 總覽 | 產品主張、示範資料統計、最新職缺、功能導覽 |
| 職缺列表 | 中英文搜尋，可依職務類型、語言要求、地區、工作型態篩選，也能儲存職缺 |
| KSA 分析 | 知識、技能、特質出現次數 |
| PM vs PjM | 七大構面雷達圖、Stage-Gate 參與比例 |
| 薪資資訊 | 雇主揭露薪資、相似職缺行情、員工回報，三者分開呈現 |
| 我的職涯規劃 | 可解釋的配適度，以及職缺專屬準備清單（存在瀏覽器 localStorage） |
| 資料與方法 | 資料來源授權狀態、設計原則、產品路線圖、更新紀錄 |
| 團隊與分工 | 組員介紹、指導老師 |

共通功能：中英文切換、亮暗模式切換、手機／平板／電腦響應式版面。

## 設計概念：登山步道

- 首頁山景：步道上的 5 個站點對應 5 個主要功能，點站點就會跳到該區；在電腦上移動滑鼠，山的圖層會有視差效果。
- 背景等高線：用 canvas 即時畫出地形等高線，會跟著滑鼠起伏，捲動頁面時地形也會跟著移動。
- 側邊欄是步道地圖：捲動時金色進度線會往下延伸，目前所在的站點會亮起來。
- 配適度用山的填滿高度表示，準備清單用攀登進度條表示。
- 系統設定為減少動態效果時，動畫和背景互動會自動關閉。

## 資料說明

網站上的 24 筆職缺都是**虛構的示範資料**，用來展示功能，不是真實的招募資訊。網站沒有使用任何 API 金鑰，也沒有串接後端。
